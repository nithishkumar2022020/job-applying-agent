Host on GitHub Pages or Cloudflare Pages

Deploy this exact GUI as a static site while it controls your local stealth agent.

Option 1: Deploy to Cloudflare Pages (Free, Fast)

  1. Push the job-applying-agent repository to GitHub.
  2. In the Cloudflare Dashboard, go to Pages → Connect to Git.
  3. Set Build output directory to web (no build command needed).
  4. Click Deploy Site!

Option 2: Deploy to GitHub Pages

  1. In your GitHub repo settings, go to Pages.
  2. Select Deploy from branch → Branch: main → Folder: /web.
  3. Save, and your GUI is live globally at https://<username>.github.io/<repo>/.
